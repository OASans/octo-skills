# 2026-05-17

## Claude Code silent ~50min request hangs = stalled stream, not slow API

Silent multi-minute hangs with no progress are stalled streams / half-open connections; raising `API_TIMEOUT_MS` alone won't fix them.
Mitigation lives in `base-settings.json` env block (deployed via `install.sh` → `~/.claude/settings.json`): `API_TIMEOUT_MS=300000`, `CLAUDE_STREAM_IDLE_TIMEOUT_MS=180000`, `CLAUDE_ENABLE_STREAM_WATCHDOG=1`, `CLAUDE_ENABLE_BYTE_WATCHDOG=1`, `CLAUDE_CODE_MAX_RETRIES=3`.
Auto stalled-stream abort+retry requires Claude Code **v2.1.105+**; on older versions the watchdog vars are harmless no-ops, so updating CC is the real fix.
Hardcoded ~5min Bun-middleware timeout (GH anthropics/claude-code#39906) is NOT env-overridable — residual hangs after these vars are likely network/proxy (try `CLAUDE_CODE_ENABLE_FINE_GRAINED_TOOL_STREAMING=0`).
**Rule:** settings.json `env` is read at process startup — env changes need a fresh `claude` launch, not just `install.sh`.
