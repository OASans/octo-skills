# 2026-05-18

## Disabling background Bash/Agent in Claude Code needs a PreToolUse hook, not env vars

(CC v2.1.143, verified against the binary.) `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS` only suppresses the advisory prompt text for the POSIX Bash and Agent tools — it does NOT reject an explicit `run_in_background:true` (only the PowerShell tool hard-omits the param from its schema). `CLAUDE_AUTO_BACKGROUND_TASKS` (note: no `CLAUDE_CODE_` prefix) only sets the long-command auto-background timer (120000ms vs 0), unrelated to the explicit parameter. The env-truthiness helper accepts `1`/`true`/`yes`/`on` (lowercased, trimmed); these flags are read once at session start so changes need a fresh `claude` launch, not just `install.sh`.
The only reliable block: a `PreToolUse` hook that denies when `.tool_input.run_in_background == true`. CC passes `tool_input` verbatim to hooks (payload keys `hook_event_name`/`tool_name`/`tool_input`/`tool_use_id`) and matches the hook `matcher` against the tool name. Deployed in `base-settings.json` as a third `PreToolUse` entry (matcher `Bash`; use `Bash|Agent` to also block background subagents); each hook on an event gets its own stdin copy, so it coexists with the octo logger hooks. Effective only after session restart.
**Rule:** to enforce policy on a tool *parameter* (not command text), use a PreToolUse deny hook — permissions match tool/command only, and the env flags are soft (prompt-text) for Bash/Agent on Linux.

## Verifying Claude Code internals = grep the version binary

The CC executable is a ~233MB not-stripped Node SEA ELF at `~/.local/share/claude/versions/<ver>`. Env-var names, Zod input schemas, hook-payload construction, and prompt text all survive as string literals. Find them with `grep -aboE <pat>` for byte offsets, then `dd if=<bin> bs=1 skip=<off-W> count=<2W> | tr -c '[:print:]' ' '` to dump a readable window (code is minified with ~no newlines, so window width — not line count — is the unit).
**Rule:** when CC docs are ambiguous about a flag/feature, the installed binary is ground truth — grep it rather than trust the docs or guess.
